# Walls and designs

**Walls** lists the browser walls and e-paper panels in your home. Each entry
shows whether the device has checked in and what design it uses. Choose **Add a
wall** to start with a tablet, monitor or television, or with an e-paper panel.

## Browser walls

Open a wall and use **Layout** to move widgets. Portrait and landscape have
separate layouts. Use the **Background** button beside **Layout** to choose
the wall's theme colour, a solid colour, gradient, uploaded image or wallpaper
for the layout currently on screen.
You can create another layout for certain hours and schedule it under **Wall
settings → Design**. That timed layout can have its own background.

Use **Wall settings → Look** for the wall's theme, daytime theme, widget ground,
default widget styling and a link to each everyday background. A background
link opens its layout's Background picker. Choosing a wallpaper offers an option
to apply it across both orientations. A widget's individual style can override
the wall's widget defaults, which in turn override the shared theme.

**Choose a starter design** replaces both orientations and their backgrounds.
Some designs also change the wall's theme; each card says whether it does. A
new wall asks for its theme separately. The selected design's preview updates
to that choice, so you can inspect the combination before adding the wall.
Copying another wall is a one-time copy of its layouts and backgrounds; the
walls do not stay linked, and the receiving wall keeps its theme.

**Themes** is the shared library. Choosing a theme on a wall affects that wall.
Editing a custom theme in the library affects every wall using it. The tags
beside each theme open those walls' Look settings.

## E-paper panels

On a panel's design page, **What this panel draws** offers three sources:

- **Built-in view:** the panel's ready-to-use black and white layout.
- **Own layout:** arrange widgets on the panel and use its own designs.
- **Follow a wall:** use a browser wall's everyday widget layout. Change the
  widget arrangement on that wall; the panel follows it.

A following panel does not receive that wall's wallpaper, theme or timed
layouts. It can use the widget's **On ink** settings to show less detail without
changing the browser wall. The panel's **Device recipes** page explains how to
give ESPHome or Home Assistant the panel's frame URL.
